# Project Overview

用于记录在 Python、机器学习、PyTorch 和医学图像分析方向的学习与实践。

## 项目说明

### `image_classification/`

基于 PyTorch 的 CIFAR-10 图像分类项目。

主要用于学习 CNN 的基本结构、模型训练、验证、测试、残差连接以及 ResNet18 等内容。

---

### `pyMIC Medical Segmentation/`

基于 PyMIC 的医学图像分割项目。

主要使用 HC18 胎儿头部超声图像进行 UNet 分割实验，并学习医学图像数据处理、配置文件、Dataset、Transform 和训练流程。

---

### `PyMIC_examples-main/`

PyMIC 示例与参考代码。

主要用于学习 PyMIC 官方项目结构、配置方式以及不同医学图像任务的实现方法。

---

### `machine learning/`

机器学习相关学习笔记与 Notebook。

---

### `python_basics/`

Python 基础学习与练习代码。

---

### `pytorch/`

PyTorch 基础学习笔记与练习代码。
